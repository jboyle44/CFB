Depth Chart
Position, jersey number, and rank order pulled from Ourlads' NFL team depth chart page.
Acquisition code
Ourlads' shorthand for how a player originally joined the roster — a draft year/round like "20/1" (2020, round 1), a street/college free agent signing like "SF23"/"CF26" (original signing year), or an inter-team move like "T/Pit" (traded from Pittsburgh), "U/Den" (waived, claimed from Denver). This reflects how they arrived, however long ago — it isn't a "recently happened" flag, so a player can show a trade/waiver/FA code from a year or more back.
PFF
PFF grade for the player. Not wired in yet — shows "—" until added.
Color scale
Once PFF grades are added, they'll color on a sliding red → yellow → green scale, low to high, so you can scan a formation and spot the strongest/weakest spots at a glance.
