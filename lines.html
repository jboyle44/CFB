How this works tap to expand

Every Tuesday, a script pulls that week's games, final scores, and market spreads from CollegeFootballData.com, plus MPG's power ratings for that week. It computes a model spread for every game and compares it to the market:

model_spread = (home_rating − away_rating) + HFA HFA = +3.0 pts for the home team, 0 on a neutral site edge = model_spread − vegas_spread pick = home team if edge > 0, away team if edge < 0

Once a game is final, the pick is graded straight against the market line that was live when it was made — that line is then frozen, so results here don't get rewritten as future lines move. A push means the actual margin landed exactly on the spread and doesn't count for or against the record.
